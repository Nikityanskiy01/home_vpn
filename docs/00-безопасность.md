# Безопасность

Никогда не добавляйте в Git: URL приватных подписок Berendey/Remnawave, ключи и пароли VPN, SSH-ключи, пароль OpenWrt/Proxmox, API-secret Mihomo и резервные копии с конфигами.

Храните такие значения в менеджере паролей. В файлах этого репозитория используйте только `YOUR_*`.

Перед скриншотом замажьте IP, если не хотите публиковать домашнюю топологию, и все QR-коды/URL подписок. Для публичного репозитория создайте отдельный ключ SSH с ограниченным доступом, а не публикуйте существующий.
