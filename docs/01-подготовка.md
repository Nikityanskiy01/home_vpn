# 1. Подготовка

## Что понадобится

- Keenetic (или другой главный роутер), который остаётся шлюзом DIRECT;
- Proxmox VE и свободные ресурсы для VM OpenWrt;
- управляемый коммутатор/точка доступа с VLAN, если SMART и FULL должны выйти за пределы Proxmox;
- образ OpenWrt, совместимый с VM; URL берите только с официального сайта OpenWrt;
- доступ к Berendey для SMART и Remnawave для FULL;
- компьютер с SSH-клиентом.

## Заполните свою карточку сети

Скопируйте [`templates/параметры-сети.example.md`](../templates/параметры-сети.example.md) в личное, некоммитимое место. Примерные адреса ниже повторяют исходный HomeLab, но вы можете выбрать другие непересекающиеся подсети.

| Поле | Пример исходной схемы | Ваше значение |
|---|---|---|
| Основной роутер | `192.168.1.1` | |
| Proxmox в домашней LAN | `192.168.1.94` | |
| WAN OpenWrt | `192.168.1.250` | |
| OpenWrt management | `10.77.0.1` | |
| Proxmox management | `10.77.0.2` | |
| SMART gateway / VLAN | `10.77.20.1` / `20` | |
| FULL gateway / VLAN | `10.77.30.1` / `30` | |

Перед продолжением убедитесь, что эти подсети не используются гостевой сетью, Docker, другим VPN или маршрутом Keenetic.

## План восстановления

Сначала убедитесь, что вы можете открыть консоль VM в Proxmox. Не начинайте изменения firewall через удалённый доступ, если у вас нет такого аварийного доступа. Сделайте резервную копию Proxmox и сохраните текущую конфигурацию роутера.
